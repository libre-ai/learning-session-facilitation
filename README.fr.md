# Libre AI Learning Session Facilitation

Préparer et suivre une session d’apprentissage avec des sources, des rôles et des responsabilités clairs. Ce produit vise les formateurs et animateurs d’ateliers qui souhaitent organiser une activité et suivre son déroulement.


## Usages visés

- Rassembler des ressources citées pour soutenir un atelier ou une formation.
- Préciser les activités des participants et les tâches qui peuvent être déléguées.
- Suivre les événements de la session et revenir sur ce qui s’est passé.

**Aujourd’hui :** ce dépôt présente le projet sous forme de documentation ; aucune application n’est encore disponible.
