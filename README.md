# Libre AI Learning Session Facilitation

## Intended use

Help a facilitator prepare and follow a learning session using cited material, explicit participant roles and bounded delegation. This preserves the learning and facilitation purpose of Sessions; it does not redefine the product as a generic login service.

## Existing candidates and limits

Earlier sources include session events and components intended to support data-subject requests and retention. A complete facilitation journey and actual exercise of those rights remain to be qualified. This documentary candidate admits no session service, verified retention guarantee or functioning organization authority.

## Organization and authentication boundaries

Cross-product integration also needs a session to be read in its organization and an organization membership to be checked. That is an authority boundary to qualify, not proof that the facilitation application already provides it. Authentication remains distinct. Where an opaque session identifier must be resolved before its organization is known, the chosen direction is a minimal opaque index followed by organization-scoped reads and membership checks; it is not an exception to organization isolation.

## Proposed contracts and activation criteria

Proposed contracts describe a session’s sources, roles, delegated actions and event history, plus the handling of local data-subject requests. Canonical formats require admission by Contracts. Qualify a complete facilitation journey, persistent organization-scoped state, explicit permission refusals and the actual data lifecycle. Test the organization-resolution boundary and cross-organization denial independently. Adopt and verify the applicable retention rules without inventing new durations here; types, callbacks and review records alone do not establish completed deletion.

The complete journey described above is a criterion for activating the product. A candidate module may be qualified and admitted separately for its own explicit scope, with its own consumer and evidence. Neither that module admission nor the documentary existence of this repository requires a complete Missions journey or completion of other future products.
